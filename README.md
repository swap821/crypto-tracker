A modern, high-performance cryptocurrency tracking dashboard built with React and Vite. This application connects to live cryptocurrency APIs to deliver real-time market data, advanced client-side filtering, dynamic routing, and interactive data visualization for the top cryptocurrencies worldwide.

The project focuses on performance optimization, clean UI/UX, responsive design, and scalable frontend architecture.

---

# 🌟 Live Features

## 📈 Real-Time Market Data
- Fetches live cryptocurrency prices
- Displays market capitalization and 24-hour trading volume
- Tracks market trends in real-time

## 📊 Interactive Price Charts
- Fully responsive 7-day historical charts
- Built using Recharts for smooth visualization
- Dynamic graph updates based on selected cryptocurrency

## 🔍 Smart Search & Filtering
- Instant client-side search functionality
- Filters crypto assets without unnecessary API requests
- Fast and optimized user experience

## 🧭 Dynamic Routing
- Built with React Router DOM v6
- Dedicated detail pages for each cryptocurrency
- Smooth navigation without page reloads

## ⚡ Optimized Performance
- Lightning-fast development using Vite
- Efficient asynchronous API handling
- Optimized rendering and reusable components

## 🚨 Error & Loading State Handling
- Graceful handling of API/network failures
- Professional loading indicators
- Improved user experience during async operations

# 🚀 Getting Started

Follow these instructions to set up the project locally.

## 📌 Prerequisites

Make sure you have the following installed:
- Node.js
- npm

Download Node.js from:
https://nodejs.org/

---

# ⚙️ Installation

## 1️⃣ Clone the Repository

```bash
git clone https://github.com/YOUR_USERNAME/crypto-tracker.git
```

---

## 2️⃣ Navigate into the Project Directory

```bash
cd crypto-tracker
```

---

## 3️⃣ Install Dependencies

```bash
npm install
```

---

## 4️⃣ Start the Development Server

```bash
npm run dev
```

---

## 🌐 Open in Browser

Visit:

```bash
http://localhost:5173
```
